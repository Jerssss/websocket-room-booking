# 9444-Team1_PreProject



## RESERVATION SYSTEM FOR TERMINALS AND EQUIPMENTS

This system allows students to reserve computer terminals and equipment for study purposes, manage their reservations, and view their reservation history. Admins can manage the terminals/equipment (add, edit, remove), approve or reject student reservations, and generate reports. The system ensures reservation rules such as a maximum of 2 hours per day and advance bookings. It features an MVC-based client-side application and a server-side system that handles data storage via XML files, logging actions, and managing multiple clients simultaneously.
